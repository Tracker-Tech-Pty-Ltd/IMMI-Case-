## How to use this

Each plan is **self-contained**: it assumes the executor has never seen this audit, this repo, or any other
plan. Read the plan fully before starting, run every verification command, honour the STOP conditions, and
update your row in the status table below when done.

Plans were partitioned by **file territory** so that non-conflicting plans can be executed in parallel by
separate agents. Where two plans share a file, they claim **disjoint regions** of it and say so explicitly in
their Scope sections — check both before dispatching them together.

## Dependency notes

These lanes were established by a gpt-5.6-sol review of all 52 plans and then verified against the code by
each plan's author. **Within a lane, plans are serial** — the second executor rebases on the first's
integrated tip. **Across lanes, plans are parallel-safe.**

|---|---|---|

| Frontend styling | `019 -> 021 -> 022`, then `023 -> 024 -> 025` | 019 and 022 both edit `frontend/src/index.css`; 022 measures contrast against the palette 021 ships. |
| Python data layer | `027 -> 028 -> 026` | successive rewrites of `immi_case_downloader/sqlite_repository.py`. |
| Extraction | `041 -> 032` | 041 writes 56 characterization tests over `extract_structured_fields.py`; 032 then inverts that module's import direction. The tests are what make 032 safe. |
| ADRs | `044` first, then `047`-`052` in any order | 044 owns `docs/adr/README.md` and `TEMPLATE.md`; every other plan creates only `docs/adr/<its own number>-*.md`. |

Cross-lane notes:

- **001 gates most frontend work.** Until `tsc -b --noEmit` is the real gate, a frontend change that breaks
  types ships green.
- **006 ships a deliberate breaking change.** After it deploys, every operator surface returns
  `403 platform_operator_required` for all users until access is granted. Two grant paths are documented in
  the plan. Do not deploy it without telling whoever runs the pipeline.
- **No plan asserts an absolute suite total.** Every Done criterion records a BEFORE value at Step 1 and
  asserts a delta, or names the specific tests it added. The 3 environmental Python failures are asserted
  by name, not by count, so a fourth failure cannot hide inside the number.
- **Every drift check reads the working tree**, not just `git diff <SHA>..HEAD`: `git status --short --branch`
  plus staged and unstaged diffs over the in-scope paths. No plan issues an unconditional `git checkout --`
  or `git clean`.
