# 2026-10-31 法官及裁決者欄位盤點

本輪以唯讀方式重新核對本機 SQLite、CSV 和 JSON 的案件識別碼及裁決者欄位。這是欄位內容盤點，不是逐案人工核實所有姓名。

## 主要案件資料

SQLite 與 CSV 各有 152,274 筆，案件識別碼及裁決者欄位逐筆一致：

- 39 筆欄位空白，與[先前 39 案清單](2026-10-27-judge-followup.md)完全相符。
- 152,235 筆欄位不空白；其中以有限規則篩出 **95 筆需要額外核對**，例如內容只有 `Hon`、數字、破折號、`Not specified`、單字、首字母或損壞文字。這些標記是待查線索，不能據此斷定每筆都錯，也不能把它們直接算成已確認姓名。

95 筆以外的非空欄位也未在本輪全部逐案核實，可能仍有資料品質問題；目前不能宣稱其他所有案件的姓名都已確認。逐筆篩選清單與規則保存在 `downloaded_cases/updates/judge-field-census-20261031/`，規則只用於找出部分明顯需關注的內容，不是完整的姓名驗證器。

## 原有 39 宗需要甚麼證據

要補回姓名，需要找到可辨認同一案件的完整判決、簽署版本或可靠官方資料，並核對案號、當事人、日期與原審法院／裁決庭，確認文件明列當時作出裁決的人。後來上訴的法官不一定是原審裁決者，不能直接代入。

先前查核發現至少 12 宗現有原文不完整，其中一宗的身分資料有衝突；其餘 27 宗尚無足夠證據確認姓名，並不代表它們的原文已證實完整。未取得足夠證據前保持空白。

## JSON 額外紀錄

JSON 有 152,281 筆，比 SQLite／CSV 多 7 筆；這七筆的裁決者欄位均空白，共同案件的欄位則一致。六筆帶有案件引註，另一筆名稱看似測試資料。七筆的識別碼、完整引註及網址均未與主要資料精確對上；尚須查證是否應納入主要資料，不能直接當成七宗已確認的新案。

## 後續與保存

下輪可先核對這 95 筆可疑內容及 JSON 額外紀錄，再持續尋找 39 宗舊案的原始資料；只有證據可對應同一案件時才備份並更新。此次沒有修改案件資料或裁決者欄位，亦沒有聲稱已核實所有非空姓名。
