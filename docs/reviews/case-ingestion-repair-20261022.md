# 本機案件下載與匯入接入核對：2026-10-22

這次修正下載後沒有進入證據核對、補下載漏掉失效路徑、匯入覆寫既有資料，以及相同案件原文版本互相覆蓋的問題。新下載、補下載及 CSV 匯入現在會留下可續用的來源、快取和缺漏原因。沒有新確認的案件欄位；沒有把無法證實的內容填成事實。

## 修正的行為

- 共用原文存檔入口會記錄案號、網址、原文指紋及各缺漏欄位的原因。CSV 案件還沒匯入 SQLite，也可先查看紀錄。
- 原文使用不同版本的檔名，保存舊內容；相同內容再次存檔不重寫。已中斷的暫存檔不會被當成完成的原文。
- 下載器先查本機來源索引。只有案號、網址、內容指紋一致，且通過正文檢查的來源才重用；檔案損壞、不同案件、短片段及多個不同版本不會直接當成完整來源。這是快取使用條件，並非獨立證明出版內容絕對完整。
- Jev 舊快取建立本機索引後只做精確查找，避免每案重讀約 495 MB 的檔案。快取意見不能核准寫入；沒有加入付費模型或付費失敗重試。
- 網頁、CLI、自動下載流程及舊批次下載只合併下載欄位。下載期間新增的人工修改、原有非空值及已刪除案件受到保護。寫入前留存備份。
- CSV 合併保留未知欄位、JSON 額外案件、順序及其他資料。舊批次下載現在也會補抓「路徑有值但檔案已不存在」的案件；續跑使用舊檔前會檢查正文。
- CSV 匯入 SQLite 只新增案件或補空白，保留資料庫原值和 SQLite 獨有案件。案號或網址衝突列在 `.last-import-review.json`，不擅自改號或合併。
- 「不適用」狀態可以透過新報表的 `fact_status` 欄重新匯入，避免因為舊、新報表欄名不同而遺失已核對的判斷。

## 驗證及費用

309 項相關測試和 10 項子測試通過，包含 31 項新增接入測試。驗證使用實際的本機 CSV、SQLite、原文檔與下載工作入口，外部回應以固定測試資料提供；包含相同內容重跑、錯案拒用、損壞快取、不同原文版本、同時人工修改、刪除保留、匯入、續跑及缺漏報表。提交前另在僅含 HEAD 加本輪提交內容的資料夾執行相同驗證，避免依賴其他未提交修改。

這是軟體及資料保留驗證，不是新一輪獨立人工正確率評估。本輪沒有放寬 Regex 或 Jev 門檻，也沒有自動核准剩餘候選。Windows／WSL 同時寫入同一批資料未驗證，仍應使用同一平台的寫入程序。

本輪外部模型費用 **US$0**。先前保守累計 **US$15.866071526**，包含 US$0.40 尚待對帳的預留額；仍低於 US$20，最終供應商帳單尚未核實。本機核對與接入流程沒有網路或付費模型呼叫；另進行 11 個公開索引搜尋查詢。

備份及本輪完整驗證位於 `downloaded_cases/updates/typesafe-ingestion-20261022/`。既有 CSV／JSON 備份與目前檔案完全相同，保留在 `downloaded_cases/updates/typesafe-workflow-20261021/backup/`。可追查數字見[本輪摘要](../data-repairs/20261022-ingestion-summary.json)。

## 查看新下載的缺漏原因

在專案目錄使用已安裝依賴的 Python 環境執行：

```text
python scripts/review_download_intake.py --base-dir downloaded_cases --output downloaded_cases/intake-review
```

輸出包含缺漏清單、來源指紋和狀態。既有原文未變且已核對的案件不需重新詢問 Jev。只有取得新的可靠原文或獨立核對證據，才應重開無法確認的欄位。
